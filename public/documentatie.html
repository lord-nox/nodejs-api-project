API Documentatie

Users

  • GET /api/users
    Haalt alle gebruikers op. 
    GET /api/users
  • GET /api/users/:id
    Haalt een specifieke gebruiker op. 
    GET /api/users/676a9652ae0822592b41f641
  • POST /api/users
    Voegt een nieuwe gebruiker toe.
    Body-structuur: 
    {
  "name": "string",
  "email": "string",
  "age": 30,
  "phone": "+32 456 78 90 12"
}
    Voorbeeld: 
    POST /api/users
Body:
{
  "name": "John Doe",
  "email": "john.doe@example.com",
  "age": 30,
  "phone": "+32 456 78 90 12"
}
  • PUT /api/users/:id
    Update een bestaande gebruiker. 
    PUT /api/users/676a9652ae0822592b41f641
Body:
{
  "name": "John Updated",
  "email": "john.updated@example.com"
}
  • DELETE /api/users/:id
    Verwijdert een gebruiker. 
    DELETE /api/users/676a9652ae0822592b41f641

NewsPosts

  • GET /api/news
    Haalt alle nieuwsartikelen op. 
    GET /api/news
  • GET /api/news/:id
    Haalt een specifiek nieuwsartikel op. 
    GET /api/news/676a9652ae0822592b41f641
  • POST /api/news
    Voegt een nieuw artikel toe.
    Body-structuur: 
    {
  "title": "string",
  "content": "string",
  "author": "string",
  "startDate": "YYYY-MM-DD",
  "endDate": "YYYY-MM-DD"
}
    Voorbeeld: 
    POST /api/news
Body:
{
  "title": "Breaking News",
  "content": "This is a test news post.",
  "author": "John Doe",
  "startDate": "2024-12-20",
  "endDate": "2024-12-25"
}
  • PUT /api/news/:id
    Update een bestaand artikel. 
    PUT /api/news/676a9652ae0822592b41f641
Body:
{
  "title": "Updated Title",
  "content": "Updated content."
}
  • DELETE /api/news/:id
    Verwijdert een artikel. 
    DELETE /api/news/676a9652ae0822592b41f641

Paginatie

  • GET /api/users/paginated?limit=...&offset=...
    Haalt een beperkt aantal gebruikers op. 
    GET /api/users/paginated?limit=5&offset=10
  • GET /api/news/paginated?limit=...&offset=...
    Haalt een beperkt aantal nieuwsartikelen op. 
    GET /api/news/paginated?limit=5&offset=10

Zoeken

  • GET /api/users/search?name=...&email=...
    Zoek gebruikers op basis van naam of e-mail. 
    GET /api/users/search?name=John
GET /api/users/search?email=john@example.com

Geavanceerd zoeken

  • GET /api/users/advanced-search
    Zoek gebruikers op basis van meerdere velden (bijv. naam, email, phone). 
    GET /api/users/advanced-search?name=John&email=john@example.com
  • GET /api/news/advanced-search
    Zoek nieuwsartikelen op basis van titel, auteur, start- of einddatum. 
    GET /api/news/advanced-search?title=Breaking&author=John&startDate=2024-01-01

Authenticatie

Er zijn ook eenvoudige auth endpoints:

  • POST /api/auth/register → registreer een gebruiker (naam, email, password, ...)
  • POST /api/auth/login → login met email en password
