Welkom bij mijn Node.js API

Dit project demonstreert een eenvoudige Node.js API met Express en MongoDB. Je kunt gebruikers (Users) en nieuwsartikelen (NewsPosts) beheren, zoeken, en geavanceerde validaties uitvoeren.

Hieronder vind je een beknopt overzicht van de functionaliteiten. Voor de volledige lijst met endpoints, zie Documentatie.

Functionaliteiten

  • Users – CRUD, zoeken, geavanceerd zoeken, paginatie.
  • NewsPosts – CRUD, zoeken, geavanceerd zoeken, paginatie.
  • Authenticatie – Registreren en inloggen.

Hoe testen?

  1. Frontend: Gebruik de Login, Register of bezoek Documentatie voor API-details.
  2. Postman / cURL:
    • GET http://localhost:3000/api/users (alle users)
    • POST http://localhost:3000/api/users (nieuwe user)
    • ... etc.
